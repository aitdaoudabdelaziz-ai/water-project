# نظام الأرشفة — جمعية الفتح للتنمية والتعاون

## شنو كاين هنا

| الملف / المجلد | شنو هو |
|---|---|
| `archive/index.html` | **البرنامج كامل** (ملف واحد). هذا هو اللي كتبدّل فيه. |
| `archive/desktop/` | الغلاف ديال الحاسوب (EXE): `main.js`، `preload.js`، الأيقونة، و`package.json`. |
| `archive/mobile/` | الغلاف ديال الهاتف (APK): `capacitor.config.json`، الأيقونة فـ`assets/`، و`package.json`. |
| `.github/workflows/archive-exe.yml` | كيصاوب EXE بوحدو فـGitHub. |
| `.github/workflows/archive-apk.yml` | كيصاوب APK بوحدو فـGitHub. |

ملي كتبدّل `archive/index.html` وكترفعو، GitHub كينسخو فالحاسوب والهاتف وكيصاوب EXE وAPK جداد.

## الطريقة 1: التبديل من GitHub نيشان (بلا حتى برنامج)

1. حل `archive/index.html` فـGitHub.
2. ضغط على ✏️ (Edit).
3. بدّل اللي بغيتي.
4. ضغط **Commit changes**.
5. سير لـ**Actions** وتسنى 5 حتى 10 دقايق، حتى يولّيو `archive-exe` و`archive-apk` خضرين ✅.
6. دخل للـrun وتحت **Artifacts** نزّل `AlFath-Archive-Windows` و`AlFath-Archive-Android`.

## الطريقة 2: التبديل فالحاسوب

1. نزّل `index.html` وحلّو بـ**Chrome**: البرنامج كيخدم مباشرة، وهكا كتجرّب.
2. بدّل فيه بـ**VS Code** أو **Notepad++** (ماشي Word).
3. سجّل الملف وعاود Refresh فـChrome باش تشوف التبديل.
4. ملي يعجبك، رفعو فـGitHub بلاصة القديم: **Add file ← Upload files** فمجلد `archive`.

## فين كاين كل حاجة داخل `index.html`

قلّب بـ`Ctrl+F` على هاد العناوين:

| ابحث على | شنو فيه |
|---|---|
| `:root` | الألوان: `--navy` (الأزرق)، `--teal`، `--gold`. |
| `const TYPES` | أنواع السجلات: وارد، صادر، تقرير مالي… |
| `لوحة القيادة` / `function vDash` | الصفحة الرئيسية والأرقام. |
| `إضافة / تعديل` / `function openForm` | استمارة الإضافة والخانات. |
| `التقارير الرسمية` / `function reportHTML` | شكل التقرير المطبوع بالشعار. |
| `const EXAMPLES` | أمثلة التقارير والمشاريع (المأوى السياحي، المسبح القروي). |
| `المستخدمون` | المستخدمين والصلاحيات. |
| `الإعدادات والنسخ الاحتياطي` | الإعدادات، الشعار، النسخة الاحتياطية. |

## قبل كل إصدار جديد

- **رقم النسخة:** زيد الرقم فـ`"version"` فـ`archive/desktop/package.json` و`archive/mobile/package.json` (مثلا من 1.1.1 لـ1.1.2).
- **الهاتف:** الـAPK كيتوقّع بنفس المفتاح ديما، داكشي علاش النسخة الجديدة كتركب فوق القديمة بلا ما تمسح البيانات.
- **البيانات:** ديما دير نسخة احتياطية من الإعدادات قبل ما تركّب نسخة جديدة.

## ملاحظات مهمة

- **المستودع عام (public):** أي واحد يقدر يشوف الكود. البيانات ديال الجمعية ماشي فيه، حيت كتبقى غير فالجهاز.
- **ما تحطّش فيه:** حتى شي كلمة سر ولا وثيقة شخصية.
- **إلى خسرتي شي حاجة:** GitHub كيحتافظ بكل النسخ القديمة فـ**History**، وتقدر ترجع ليها.
