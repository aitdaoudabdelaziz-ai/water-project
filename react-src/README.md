# برنامج الماء — نسخة React

نقطة البداية: `src/App.js`. تُبنى إلى `../react/` وتُنشر على **alfath-eau.org/react/**.

| المرحلة | المحتوى | الحالة |
|---|---|---|
| 1 | App.js، التنقل، التصميم، لوحة القيادة، المشتركون، الفواتير (عرض)، فتح النسخ الاحتياطية (عادية ومشفّرة) | ✅ |
| 2 | القراءات (مع العدّاد)، إصدار الفواتير، الدفع وإلغاؤه، التحصيل السريع، واتساب، حفظ نسخة تُفتح في البرنامج الأصلي + هوية بصرية جديدة | ✅ |
| 3 | المالية، الإعدادات والأشطر، المستخدمون والصلاحيات (نفس كلمات السر)، طباعة الفاتورة والوصل | ✅ |
| 4 | السحابة (Firebase) بنفس بيانات البرنامج الحالي، ثم استبداله (الموقع + APK + EXE) | ⏳ |

- `src/lib/calc.js`: نفس حسابات البرنامج الأصلي حرفياً.
- الهوية: «واحة وخطّارة» — حبر الحوض #0E2F3D، أزرق الساقية #1B7FA8، أخضر النخيل #2F7D52، الزعفران #C98F12، الرمان #B03A48؛ خط Noto Kufi Arabic مُضمَّن (يعمل بدون إنترنت).
- نسخة React **لا تكتب أبداً** في بيانات البرنامج الأصلي (`w1` / `w1c`)؛ نسختها الخاصة في `w1react`.
- البناء: `npm install && npm run build` (أو `node build.mjs`).
- الاختبارات: `node --test e2e/f14-react.spec.mjs e2e/f15-react-edit.spec.mjs e2e/f16-react-admin.spec.mjs` (تقارن أرقام لوحة القيادة والفواتير مع البرنامج الأصلي).
