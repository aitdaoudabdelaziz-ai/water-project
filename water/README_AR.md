# برنامج الماء — جمعية الفتح (نسخة سحابية + EXE + APK)

مستودع واحد على GitHub يُنتج ثلاث نسخ من نفس البرنامج:

| النسخة | من أين | الملف |
|---|---|---|
| نسخة سحابية (تعمل في المتصفح وتُثبَّت على الهاتف) | GitHub Pages | رابط `https://اسمك.github.io/water-project/` |
| ويندوز | GitHub Actions → `AlFath-Water-Windows` | `AlFath-Water-Setup-1.0.0.exe` (تثبيت) و `AlFath-Water-Portable-1.0.0.exe` (بدون تثبيت) |
| أندرويد | GitHub Actions → `AlFath-Water-Android` | `AlFath-Water-1.0.0.apk` |

## الخطوات (مرة واحدة)

1. ادخل إلى github.com وأنشئ مستودعاً جديداً باسم `water-project` (اختر Private إن أردت).
2. فكّ ضغط الملف `water-project.zip` على حاسوبك.
3. في صفحة المستودع اضغط **Add file ← Upload files**، واسحب **كل محتوى** المجلد (بما فيه المجلد `.github`) ثم **Commit changes**.
   - إن لم يظهر المجلد `.github` (مخفي)، أنشئ الملفين يدوياً: **Add file ← Create new file** واكتب الاسم `.github/workflows/build.yml` والصق محتواه، وكذلك `pages.yml`.
4. افتح تبويب **Actions**؛ سيبدأ «Build EXE + APK» تلقائياً (حوالي 10–15 دقيقة).
5. عند ظهور العلامة الخضراء ✔ افتح التشغيل، وفي أسفل الصفحة قسم **Artifacts** نزّل:
   - `AlFath-Water-Windows` (فيه ملفّا exe)
   - `AlFath-Water-Android` (فيه ملف apk)

## النسخة السحابية (GitHub Pages)

1. في المستودع: **Settings ← Pages ← Source: GitHub Actions**.
2. **Actions ← Publish web version ← Run workflow**.
3. الرابط يظهر في نهاية التشغيل. افتحه في Chrome على الهاتف ثم «إضافة إلى الشاشة الرئيسية» ليعمل كتطبيق حتى بدون إنترنت.
   - تنبيه: إن كان المستودع Private فـ GitHub Pages يتطلب اشتراكاً مدفوعاً؛ اجعله Public أو استعمل EXE/APK فقط.

## تثبيت APK على الهاتف

نزّل الملف على الهاتف ← افتحه ← اسمح بـ«التثبيت من مصادر غير معروفة» عند الطلب. هذه نسخة غير موقّعة للمتجر (debug)، وهي صالحة للاستعمال داخل الجمعية.

## مهم عن البيانات

- كل نسخة (السحابية، الحاسوب، الهاتف) تحفظ بياناتها في جهازها فقط. البيانات **لا تنتقل وحدها** بين الأجهزة.
- لنقل البيانات: «الإعدادات ← نسخة احتياطية ← حفظ نسخة» في جهاز، ثم «استرجاع» في الجهاز الآخر.
- في نسخة ويندوز: نسخة تلقائية كل يوم وعند الإغلاق في مجلد `المستندات\AlFath-Water-Backups`، ويمكن إضافة مجلد ثانٍ (فلاشة أو OneDrive).
- في نسخة أندرويد: «حفظ نسخة» يفتح نافذة المشاركة؛ اختر Drive أو واتساب أو «الملفات» لحفظها.

## التحديث لاحقاً

عدّل `www/index.html` (أو ارفع النسخة الجديدة مكانه)، وغيّر رقم الإصدار في `desktop/package.json` و `www/sw.js`، ثم Commit؛ تُبنى النسخ الجديدة تلقائياً. تثبيت EXE الجديد فوق القديم يحافظ على البيانات.
